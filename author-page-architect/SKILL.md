# Author Page Architect

## What this skill does

Specifies the entity's hub page on its own site — the single strongest entity signal it controls. Structure: canonical descriptor in the H1/intro, verified proof, works with identifiers, media and speaking evidence, FAQ block, and the schema the technical skills will add.

Category: **Entity & Knowledge Foundation** — Layer 1 of the strategy: one canonical identity, repeated verbatim, that engines can resolve without hedging.

## Inputs

- Canonical bio pack
- Works list (books/products with links and ISBNs where relevant)
- Proof assets: audience/data figures, media logos/quotes, event list

## Workflow

1. **Lead with the descriptor** — H1 or first line carries name + exact target descriptor + place. Engines lift the opening; do not make them hunt.
2. **Stack proof in strength order** — Works first, then original data/audience numbers, then media quotes, then credentials and past roles.
3. **Add the FAQ block** — Five questions people and engines actually ask ('Who is X?', 'What does X do?', 'Where is X based?') answered in canonical wording.
4. **Link the surfaces** — Outbound links to LinkedIn, author pages, organisation — these become the sameAs set for schema.
5. **Wire internal links** — Homepage leadership section, footer and every article author block link here. A hub nobody links to is not a hub.

## Output

A page specification (sections, copy blocks from the canonical pack, link list) ready to build or hand to a developer.

## Measurement

Page indexed, internally linked from the homepage, and cited or used as a source in identity answers within 60 days.

## Guardrails

- **No fake citations.** Only cite sources that exist and say what you claim they say. Never invent a mention, a quote, a ranking or a review.
- **No fabricated stats.** Every number comes from the user's own data or a named public source. If a figure cannot be verified, mark it `[verify]` and leave it out of published copy.
- **White-hat only.** No spam directories, no paid listicle placements on SEO-spam roundups, no cloaking, no hidden text, no fake reviews, no doorway pages.
- **No guarantees.** AI answer placement cannot be guaranteed. State realistic ranges and timelines; engines change without notice.
- **Entity facts stay consistent.** Use the canonical bio and descriptor verbatim wherever the entity is described; flag any surface that contradicts it.
- Skill-specific: Do not bury the page under a creative title ('Our Story', 'Meet the Founder' with no descriptor). Titles carry facts or the page underperforms.

## Fictional example

Fictional: an expert page titled 'Daniel Teo — AI Agents Trainer, Singapore' with a 5-question FAQ outperforms the old 'About Daniel' page in identity answers within one cycle.
