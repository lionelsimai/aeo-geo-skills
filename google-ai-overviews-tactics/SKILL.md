# Google AI Overviews Tactics

## What this skill does

AI Overviews are generated from Google's index and favour pages that already rank, answer directly and structure facts cleanly. This skill audits which of the entity's target queries trigger overviews, which sources they cite, and closes the owned-page gaps.

Category: **Platform Surfaces** — Layer 4 of the strategy: each engine retrieves and cites differently — per-engine tactics grounded in observed citation behaviour.

## Inputs

- Target query set (tier map)
- Current classic rankings for those queries (Search Console)

## Workflow

1. **Find the triggering queries** — Check which target queries actually show an overview; not all do, and effort follows the ones that do.
2. **List the cited sources** — Per overview, the cited domains and the specific pages. Note how many are already top-10 organic results.
3. **Fix the ranking floor first** — Overviews rarely cite pages Google does not rank. Classic SEO on the target page (title, links, depth) precedes any AIO-specific work.
4. **Structure for the lift** — Direct answer near the top, standalone stats, clear subheadings — the structures the citation-source audit shows being lifted.
5. **Track separately** — Log AIO presence/citations apart from generic engine scores; overview behaviour changes independently and often.

## Output

An AIO worksheet per target query (triggers?, cited sources, owned-page gap, action) and the fixes shipped.

## Measurement

Cited-in-overview rate for triggering target queries, checked monthly; classic position of the cited owned page tracked alongside.

## Guardrails

- **No fake citations.** Only cite sources that exist and say what you claim they say. Never invent a mention, a quote, a ranking or a review.
- **No fabricated stats.** Every number comes from the user's own data or a named public source. If a figure cannot be verified, mark it `[verify]` and leave it out of published copy.
- **White-hat only.** No spam directories, no paid listicle placements on SEO-spam roundups, no cloaking, no hidden text, no fake reviews, no doorway pages.
- **No guarantees.** AI answer placement cannot be guaranteed. State realistic ranges and timelines; engines change without notice.
- **Entity facts stay consistent.** Use the canonical bio and descriptor verbatim wherever the entity is described; flag any surface that contradicts it.
- Skill-specific: Do not chase overviews with thin 'AIO content'. The overview is a summary of the index — the index position is the game.
