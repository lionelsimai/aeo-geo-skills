# AI Baseline Measurement

## What this skill does

Builds the measurement foundation every later AEO claim depends on: a frozen prompt set split into tiers, a scoring rubric, and a run sheet that a different person could repeat and get the same baseline.

Category: **AEO/GEO Strategy & Audits** — Know where the brand stands in AI answers before spending anything: audits, baselines, share of voice and roadmaps.

## Inputs

- The entity and its target query tiers (Tier 1 prize queries, Tier 2 adjacent, Tier 3 identity)
- Engines in scope
- The baseline date and who runs it

## Workflow

1. **Freeze the prompt set** — 10-15 prompts: 3 Tier 1, 4-6 Tier 2, 1-2 identity ('Who is X?'), 2 branded controls. Freeze wording; changes restart the baseline.
2. **Define the rubric** — Score mentioned (0/1), position (first / middle / last third), descriptor accuracy (correct / partial / wrong), cited (is the owned site cited).
3. **Run and record raw** — Save full answers with engine, date and session type in a log before scoring anything.
4. **Publish the baseline** — One page: scores per tier, the method, and the caveats. Date it. This is the number all future reports compare against.
5. **Schedule the rerun** — Monthly, same prompts, same rubric, same engine list. Note engine product changes in the log when they happen.

## Output

A baseline sheet (prompt set + rubric + scores) and a one-page baseline summary that can be shown to a client or board.

## Measurement

The baseline IS the metric. Success of later work = movement against it on Tier 2 first (60 days), Tier 1 later (90-180 days).

## Guardrails

- **No fake citations.** Only cite sources that exist and say what you claim they say. Never invent a mention, a quote, a ranking or a review.
- **No fabricated stats.** Every number comes from the user's own data or a named public source. If a figure cannot be verified, mark it `[verify]` and leave it out of published copy.
- **White-hat only.** No spam directories, no paid listicle placements on SEO-spam roundups, no cloaking, no hidden text, no fake reviews, no doorway pages.
- **No guarantees.** AI answer placement cannot be guaranteed. State realistic ranges and timelines; engines change without notice.
- **Entity facts stay consistent.** Use the canonical bio and descriptor verbatim wherever the entity is described; flag any surface that contradicts it.
- Skill-specific: Do not quietly edit prompts mid-programme to make scores improve. A changed prompt set invalidates the comparison.

## Fictional example

Fictional: a B2B SaaS founder freezes 12 prompts. Baseline: branded 2/2, Tier 2 1/6, Tier 1 0/3, identity answer wrong. That one page drives the next quarter's work.
