# Canonical Bio Builder

## What this skill does

Produces the single source of truth for an entity: a one-liner, a 50-word and a 150-word bio built from verified facts only, with the target descriptor placed exactly where engines lift it — name, descriptor, organisation, place, proof.

Category: **Entity & Knowledge Foundation** — Layer 1 of the strategy: one canonical identity, repeated verbatim, that engines can resolve without hedging.

## Inputs

- Verified facts: full name, current role/descriptor, organisation, base location
- Proof points that can be evidenced (books with ISBNs, audience numbers, credentials, notable roles)
- Any namesake/collision risks

## Workflow

1. **Fix the descriptor** — Choose the exact phrase the entity wants to own (e.g. 'agentic AI expert'). One phrase, used everywhere; near-synonyms dilute resolution.
2. **Draft the one-liner** — Name + descriptor + organisation + place in a single sentence. This is the sentence journalists and engines should repeat.
3. **Build 50 and 150-word versions** — Same opening facts, then proof in descending strength: works (books/products), audience/data, credentials, past roles.
4. **Verify every claim** — Each proof point must trace to a public source. Unverifiable claims are cut, not softened.
5. **Freeze and version it** — Date the bio, name an owner, and list where it must be pasted. Any future edit updates every surface or none.

## Output

A bio pack: one-liner, 50-word, 150-word versions + a surface checklist of where each version goes.

## Measurement

Adoption = % of the entity's top 15 surfaces carrying the current version verbatim. Target 100% before any corroboration push.

## Guardrails

- **No fake citations.** Only cite sources that exist and say what you claim they say. Never invent a mention, a quote, a ranking or a review.
- **No fabricated stats.** Every number comes from the user's own data or a named public source. If a figure cannot be verified, mark it `[verify]` and leave it out of published copy.
- **White-hat only.** No spam directories, no paid listicle placements on SEO-spam roundups, no cloaking, no hidden text, no fake reviews, no doorway pages.
- **No guarantees.** AI answer placement cannot be guaranteed. State realistic ranges and timelines; engines change without notice.
- **Entity facts stay consistent.** Use the canonical bio and descriptor verbatim wherever the entity is described; flag any surface that contradicts it.
- Skill-specific: Do not let each platform 'improve' the wording. Verbatim repetition is the mechanism; paraphrase is the failure mode.

## Fictional example

Fictional: 'Maya Chen is a maritime AI expert in Singapore, founder of PortLogic, and author of Smart Ports (2025).' — one line, every fact checkable.
