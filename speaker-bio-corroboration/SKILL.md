# Speaker Bio Corroboration

## What this skill does

Event pages are high-authority third-party surfaces engines read closely. This skill systematises them: the bio pack goes out with every speaking confirmation, and each live event page is checked and logged as a corroboration asset.

Category: **Third-Party Corroboration** — Layer 3 of the strategy: independent sources describing the entity the same way — the layer that actually moves prize queries.

## Inputs

- Canonical bio pack (all lengths — events ask for different word counts)
- The speaking pipeline/calendar

## Workflow

1. **Send the pack at confirmation** — 50-word and 150-word bios, headshot, exact talk title with the query phrase where natural, and the entity links.
2. **Forbid the old-bio shortcut** — Tell organisers explicitly: do not copy the bio from last year's page or a search result. Offer the current version as the easy path.
3. **Verify the live page** — When the agenda publishes, check descriptor, org, links and talk title. Errors get one polite correction with the right text pasted in.
4. **Log the asset** — Each verified event page joins the corroboration register with URL and date — the audit team reuses it as evidence.
5. **Repurpose the appearance** — Talk recording/slides become an owned article (repurpose-talks-into-articles) so the appearance compounds instead of expiring.

## Output

A speaker-page register (event, URL, bio verified, descriptor correct) maintained per appearance.

## Measurement

% of live event pages carrying the current canonical bio (target 100%); register grows with every appearance.

## Guardrails

- **No fake citations.** Only cite sources that exist and say what you claim they say. Never invent a mention, a quote, a ranking or a review.
- **No fabricated stats.** Every number comes from the user's own data or a named public source. If a figure cannot be verified, mark it `[verify]` and leave it out of published copy.
- **White-hat only.** No spam directories, no paid listicle placements on SEO-spam roundups, no cloaking, no hidden text, no fake reviews, no doorway pages.
- **No guarantees.** AI answer placement cannot be guaranteed. State realistic ranges and timelines; engines change without notice.
- **Entity facts stay consistent.** Use the canonical bio and descriptor verbatim wherever the entity is described; flag any surface that contradicts it.
- Skill-specific: A stale organiser-written bio on a major conference site can outrank your own page. Verification is not optional admin; it is the skill.

## Fictional example

Fictional: a summit page describes the speaker by a role from two jobs ago; caught at verification, corrected before the event — and before engines snapshot it.
