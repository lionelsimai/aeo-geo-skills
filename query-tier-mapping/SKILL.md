# Query Tier Mapping

## What this skill does

Builds the query map behind an AEO programme: Tier 1 prize queries (category + geography), Tier 2 adjacent queries (roles, niches, use cases — winnable sooner), Tier 3 identity queries, plus branded controls. Each tier maps to a different asset type.

Category: **AEO/GEO Strategy & Audits** — Know where the brand stands in AI answers before spending anything: audits, baselines, share of voice and roadmaps.

## Inputs

- Entity, category, geography and niches
- Current audit/baseline if one exists
- The entity's real proof (events, books, data, clients it can name)

## Workflow

1. **Draft Tier 1** — 3-5 'best/top/leading [category] in [place]' prompts. These are assembled from roundups — they need corroboration, not just content.
2. **Draft Tier 2** — 6-10 prompts from real specialisms: role + place, tool + place, audience + outcome. Each must have an owned answer-first asset behind it.
3. **Add Tier 3 and controls** — 'Who is [entity]?' plus 2 branded prompts. Tier 3 is fixed by bio consistency, fully within your control.
4. **Map assets to tiers** — Tier 1 -> corroboration plan. Tier 2 -> query-targeted articles. Tier 3 -> canonical bio everywhere.
5. **Set expectations per tier** — Write the realistic horizon next to each tier (Tier 3: 30 days; Tier 2: 60; Tier 1: 90-180) so nobody promises the prize first.

## Output

A tier map table: prompt, tier, winning asset type, current status, realistic horizon.

## Measurement

Coverage = tiers with a live asset and a baseline score. Review the map monthly; promote a Tier 2 query to Tier 1 only after it is being cited.

## Guardrails

- **No fake citations.** Only cite sources that exist and say what you claim they say. Never invent a mention, a quote, a ranking or a review.
- **No fabricated stats.** Every number comes from the user's own data or a named public source. If a figure cannot be verified, mark it `[verify]` and leave it out of published copy.
- **White-hat only.** No spam directories, no paid listicle placements on SEO-spam roundups, no cloaking, no hidden text, no fake reviews, no doorway pages.
- **No guarantees.** AI answer placement cannot be guaranteed. State realistic ranges and timelines; engines change without notice.
- **Entity facts stay consistent.** Use the canonical bio and descriptor verbatim wherever the entity is described; flag any surface that contradicts it.
- Skill-specific: Do not stuff the map with volume keywords. Ten prompts you actually track beat two hundred you never re-run.
