# Real Estate AI Visibility

## What this skill does

Property answers cite area knowledge and trustworthy agent facts. This skill builds area guides with real data (prices cited from official/portal statistics with dates), agent entity profiles, and listing-fact accuracy across portals — no hype, no stale listings presented as live.

Category: **Local & Vertical AEO** — The five layers applied per vertical: local businesses, B2B SaaS, ecommerce, professional services and more — same discipline, different surfaces.

## Inputs

- Areas genuinely served with transaction/knowledge depth
- Agent credentials and agency facts
- Data sources for area statistics (official releases, portal data — dated)

## Workflow

1. **Build area guides from data** — Per area: price ranges with source + date, stock types, transport/schools facts. Dated and refreshed — stale area data is worse than none.
2. **Create agent entities** — Per agent: canonical bio, areas, track record stated verifiably (volumes/rankings only with portal/agency evidence).
3. **Keep listing facts clean** — Portals and own site agree on live listings; sold/expired listings marked as such everywhere. Engines recommending dead listings burn trust.
4. **Answer mover questions** — Guides for 'Cost of buying in [area]', '[Area] vs [area]', process explainers — the research prompts before any enquiry.
5. **Track area prompts** — 'Best area for [need] in [city]', '[area] property prices', 'agent for [area]' — per area, monthly.

## Output

Area guide set + agent entity packs + a listing-accuracy routine.

## Measurement

Citations of area guides in area prompts; listing-fact conflicts across portals at zero on spot checks.

## Guardrails

- **No fake citations.** Only cite sources that exist and say what you claim they say. Never invent a mention, a quote, a ranking or a review.
- **No fabricated stats.** Every number comes from the user's own data or a named public source. If a figure cannot be verified, mark it `[verify]` and leave it out of published copy.
- **White-hat only.** No spam directories, no paid listicle placements on SEO-spam roundups, no cloaking, no hidden text, no fake reviews, no doorway pages.
- **No guarantees.** AI answer placement cannot be guaranteed. State realistic ranges and timelines; engines change without notice.
- **Entity facts stay consistent.** Use the canonical bio and descriptor verbatim wherever the entity is described; flag any surface that contradicts it.
- Skill-specific: Never present projected returns as facts or keep sold listings dressed as available. Property advertising rules and basic honesty agree here.
